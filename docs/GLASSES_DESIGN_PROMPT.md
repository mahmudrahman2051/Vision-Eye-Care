# VISION EYE CARE — GLASSES.COM-INSPIRED DESIGN PROMPT

## Purpose

Use this document as a design-direction prompt for building the Vision Eye Care ecommerce website.

The reference is Glasses.com, studied from its publicly accessible homepage and eyewear listing structure. Recreate the underlying UX patterns and level of polish with the Vision Eye Care brand. Do not copy Glasses.com's logo, proprietary assets, source code, exact text, or pixel-level visual identity.

Reference patterns observed:
- Promotional announcement hierarchy
- Multi-level ecommerce navigation
- Product-first shopping
- Product carousels
- Editorial promotional cards
- Guided shopping flow
- Premium brand discovery
- Lens education
- Trust/service information
- Insurance/benefit-oriented shopping support

---

# 1. CORE DESIGN DIRECTION

Build Vision Eye Care as a:

- Premium eyewear ecommerce platform
- Modern optical retailer
- Product-first shopping experience
- Editorial fashion + optical experience
- High-trust ecommerce website
- Mobile-first responsive interface
- Fast, clean, structured shopping system

The design should feel:

**Premium + Minimal + Modern + Confident + Optical + Fashion-forward**

Do not make it look like a generic ecommerce template.

# 29. TYPOGRAPHY

Use a premium modern sans-serif:
- Inter
- Manrope
- DM Sans
- Helvetica Neue

Suggested hierarchy:
- Hero: `clamp(3rem, 7vw, 7rem)`
- Page heading: `clamp(2.25rem, 4vw, 4rem)`
- Section heading: `2rem–3rem`
- Product title: `1rem–1.125rem`
- Body: `0.95rem–1rem`

Avoid excessive font weights.
